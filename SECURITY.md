# Security policy

## Supported version

The current `0.1.x` line receives security fixes.

## Reporting

Use the repository host's private vulnerability-reporting channel when available. Do not open a public issue containing a Timeline export, coordinates, map credentials, Remotion keys, or browser-storage screenshots.

Include a minimal synthetic reproduction and browser/version information. Real location history is not required to investigate parser, persistence, cache, or rendering defects.
