# Changelog

All notable public changes are documented here. Pre-publication history is not reconstructed because this directory contains no verifiable Git history.

## 0.1.0 - 2026-08-23

- Added browser-only Timeline import and persistence.
- Added browser-side MP4 rendering.
- Added service-worker map caching and static export deployment.
- Added Korean and English application localization.
- Reduced marker types to emoji and circle.
- Reduced playback timing to cinematic and fixed duration with shared distance influence.
- Added predictive next-pin camera interpolation.
- Added editor timecode, phase progress, and keyboard shortcuts.
- Added local reset controls, public documentation, privacy disclosure, and MIT licensing.
- Opened the Studio directly with 20 deterministic sample stories, upload, and drag-and-drop.
- Unified form labels, optional help icons, focus styling, and accessible control names.
- Added automatic direction-aware emoji markers with a high-contrast badge.
- Added editable journey title and subtitle, three label styles, and eight label positions.
- Added click-to-jump progress and limited player shortcuts to the focused workspace.
- Added direct browser loading and caching of online OpenFreeMap tiles without a bundled map archive.
- Added independent recovery states for boot, import, map, and render operations.
- Added a 720-combination synthetic motion matrix, accessibility checks, and Chrome performance budgets.
- Added a respectful prior-art acknowledgement for `mahlernim/google-timeline-visualizer`.
- Kept Timeline selection and status feedback usable when DevTools is docked or the viewport is narrow.
- Fixed low-contrast map status text, playback-rate naming, and the missing browser icon request.
- Cached browser-render capability checks by output dimensions to prevent repeated WebGL context creation.
- Reduced camera shake with continuous center splines, bounded cinematic swoop, next-pin crossfades, and FPS-aware pan limits.
